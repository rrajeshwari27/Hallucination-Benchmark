Hallucination Benchmark – Testing Free AI Chatbots

Project Description

This project is a Python-based GUI prototype used to compare AI chatbot answers with reference answers and review possible inaccuracies.

Features

- Enter questions and chatbot answers.
- Compare chatbot answers with reference answers.
- Display Correct or Needs Review status.
- Add checked results to a table.
- Calculate accuracy based on checked results.
- Export benchmark results to CSV.

Technologies Used

- Python
- Tkinter
- CSV
- Difflib

How to Run

1. Install Python.
2. Download the project file.
3. Open the project folder.
4. Run benchmark_updated.py.

Note

This prototype uses text similarity as a comparison aid. It does not automatically verify factual correctness. Manual fact-checking is required.
